📋 SIPATUH

Sistem Informasi Pencatatan Aktivitas Terpadu Harian
Versi 2.0 • Laravel 13 • 2026
1. Pendahuluan

SIPATUH adalah aplikasi pencatatan aktivitas harian karyawan yang memisahkan aktivitas rutin dan aktivitas proyek. Aplikasi ini memungkinkan:

  • User mencatat aktivitas harian (status + detail)
  • User mengusulkan aktivitas baru → atasan approve/reject
  • Atasan menilai KPI bawahan dengan bobot pekerjaan
  • Admin mengelola master data & seluruh sistem
2. Jenis Aktivitas

🔄 Aktivitas Rutin

  • Daily – setiap hari
  • Weekly – hari tertentu setiap minggu
  • Monthly – tanggal tertentu setiap bulan
Contoh: Rekonsiliasi Bank

🚀 Aktivitas Proyek

  • Tanggal Mulai – kapan dikerjakan
  • Tanggal Berakhir – deadline
  • Tanggal Selesai – realisasi
Contoh: Hitung SketchUp, BOQ/BOM
3. Alur Bisnis Utama
1️⃣ Setup Master 2️⃣ Usulkan Aktivitas 3️⃣ Approve/Reject 4️⃣ Catat Harian 5️⃣ Hitung KPI 6️⃣ Laporan
  • Usulan: User buat usulan → status pending → notif atasan → atasan approve/reject → jika approve, aktivitas muncul di dashboard.
  • Pencatatan: User pilih status (Belum/Progress/Selesai) + detail → simpan.
  • Penilaian KPI: Atasan pilih bulan → sistem hitung otomatis → atasan simpan nilai akhir.
4. Rumus KPI & Grade
Nilai KPI = ( Σ (Bobot × Nilai Status) ) / ( Σ Bobot Maksimal ) × 100
Selesai = 1.0 Progress = 0.5 Belum = 0
